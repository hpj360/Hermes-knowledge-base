# Checklist

## 1. 产品定位验证（对应 spec §1）
- [ ] 愿景与使命明确（10 年愿景 + 3 年使命，可向团队与用户讲述）
- [ ] 一句话定位清晰，三个关键词（个人 / 知识工作台 / 酒类）各有指向
- [ ] 产品边界 Do/Don't 明确，"不做电商 / 不做 B 端 / 不做社交 / 不做品类扩张" 被团队认同
- [ ] 定位差异化矩阵覆盖 4 类竞品（通用 AI / 通用笔记 / 内容平台 / 工具 App）
- [ ] 三阶价值主张（L1 知识可信 → L2 实践可用 → L3 持续成长）有对应衡量指标
- [ ] 四大目标场景可验证：学习 / 实践 / 创作 / 管理
- [ ] 产品演进路径明确（Now 个人 → Next 协作 → Future 社区）
- [ ] 护城河分阶段构建（短期垂直深度 → 中期数据飞轮 → 长期网络效应）

## 2. 市场与用户验证（对应 spec §2 + §3）
- [ ] TAM/SAM/SOM 三层市场量化估算完成（2 亿 / 3000 万 / 5 万）
- [ ] 市场趋势表至少覆盖 6 项趋势，每项有"对产品策略的影响"
- [ ] 直接竞品分析覆盖 Mixology/Untappd/Punch/酒博士（含用户量级、商业模式）
- [ ] 间接竞品分析覆盖 ChatGPT/Notion AI/Dify/小红书（含"用户为什么不满意"）
- [ ] SWOT 矩阵聚焦最直接对手（Mixology），并产出 SO/WO/ST/WT 战略结论
- [ ] 机会窗口期明确（18 个月），关闭窗口的 4 个信号已定义
- [ ] 竞争策略明确（差异化四角：垂直 / 可信 / 闭环 / 自主）
- [ ] 三类用户画像定义清晰：进阶爱好者(60%) / 专业调酒师(25%) / 内容创作者(15%)
- [ ] 每类画像完成六维度（基础属性 + 行为特征 + JTBD + 痛点 + 决策路径 + 用户旅程）
- [ ] 每类画像的 JTBD 包含功能性 / 情感性 / 社会性 Job
- [ ] 画像优先级矩阵完成（用户价值 × 获取难度 → P0/P1/P2 资源占比）
- [ ] 画像 → 功能需求映射矩阵完成（每功能对应画像主/辅需求 + 优先级）

## 3. 迭代方向推导验证（对应 spec §4）
- [ ] 画像痛点 → 方向映射矩阵完成（10+ 痛点全部覆盖）
- [ ] 优先级判定四要素打分完成（用户价值 / 技术可行性 / 战略契合度 / 紧迫性）
- [ ] 方向依赖关系图完成（V1→V2→V3→V4 的依赖与反向依赖）
- [ ] "为什么是这四个方向、为什么是这个顺序"的论证逻辑可向团队讲述
- [ ] 每个方向有战略意图 + 现状诊断 + 用户价值 + 产品目标 + 关键举措 + 成功标准
- [ ] 方向一有验证假设（H1/H2/H3），并标注已验证 / 待验证状态
