# 产品平台重新审查与设计 Spec

## Why

当前 Hermes KB 平台存在两大核心问题：

1. **产品定位不清晰**：原定位"私人酒类知识管家"（文档问答）与实际已实现的"鸡尾酒实验室"（配方匹配/翻译/IBA 数据集）两个核心方向割裂，缺乏统一叙事；目标用户在"酒类爱好者/从业者/调酒师/内容运营"之间摇摆，无主用户；价值主张分散在"引用溯源/配方匹配/IBA 数据集"三处，无法形成合力。

2. **功能模块设计粗糙**：5 个一级 tab 平铺无主次；"实验室"与"配方"功能重叠；"管理"仅标签管理过于单薄；缺少首页/仪表盘/历史回顾入口；冷启动引导断裂；导航缺乏分组；"导入"按钮与文档 tab 功能重复。

本 spec 旨在以产品专家视角重新定义产品定位，系统梳理功能模块，优化信息架构与用户体验流程，明确各模块功能边界与交互逻辑。

## What Changes

### 产品定位重定义
- **BREAKING** 将产品从"私人酒类知识管家"升级为"**个人酒类知识工作台**"（Personal Liquor Knowledge Workspace）
- 统一叙事：**"从知识到实践"** — 沉淀酒类知识（文档）→ 智能检索（问答）→ 实践应用（配方/实验室）
- 明确主用户：**鸡尾酒/酒类爱好者兼内容创作者**（合并"囤积者"与"创作者"画像）
- 提炼三阶价值主张：知识可信（引用溯源）→ 实践可用（配方工具）→ 持续可成长（飞轮健康度）

### 信息架构重构
- **BREAKING** 将 5 个平铺 tab 重组为 3 大区域 + 首页：
  - **首页**（/）：价值认知入口 + 快捷操作 + 飞轮健康度概览
  - **知识区**：问答（/chat）+ 文档库（/docs）
  - **调酒区**：配方（/recipes）+ 实验室（/lab）
  - **设置区**（/settings）：标签管理 + 数据导出 + 审计日志（合并原"管理"）
- 新增首页 Dashboard：整合飞轮健康度、最近问答、推荐配方、快捷导入
- 新增历史回顾入口：问答历史搜索（/chat/history）

### 功能边界明确
- **问答**：纯检索层，引用跳转文档，不承载配方管理
- **文档**：知识源管理，被动被问答引用，与配方解耦
- **配方**：结构化配方库（IBA + UGC + 外部源），独立的配方治理流程
- **实验室**：配方创作与实验工具（材料匹配/翻译/变体），产出的配方回流到配方库
- **标签**：升级为跨知识/配方的统一组织工具，从"管理"移至"设置"

### 用户体验流程优化
- 冷启动引导链补全：年龄门 → 首页价值认知 → 种子导入 → 首次问答 → 溯源引导
- 全局导航分组：主区域（知识/调酒）+ 次区域（设置）
- 顶部"导入"按钮改为上下文感知：在文档 tab 显示"导入文档"，在配方 tab 显示"创作配方"
- 配方创作流闭环：实验室实验 → 保存为草稿 → 配方库编辑 → 发布

## Impact

- Affected specs: `design-system-refactor`（视觉层已就绪，本 spec 聚焦产品/IA 层）、`ui-consistency-review`
- Affected code:
  - `web/src/App.tsx`（导航结构 + 路由重组）
  - `web/src/components/`（新增 DashboardPanel/HistoryPanel/SettingsPanel，调整现有面板入口）
  - `src/hermes_kb/api/`（新增 dashboard/history 端点，如已存在则复用）
  - `src/hermes_kb/lab_dashboard.py`（飞轮健康度数据源，可能复用）

## ADDED Requirements

### Requirement: 首页 Dashboard
系统 SHALL 提供首页（/），作为用户价值认知入口与快捷操作中心。

#### Scenario: 首次访问首页
- **WHEN** 用户通过年龄门与登录后首次进入应用
- **THEN** 重定向到首页（/）而非问答页（/chat）
- **AND** 展示品牌 Hero 区（一句话价值主张 + 三个核心能力卡片）
- **AND** 展示飞轮健康度概览（文档数/问答数/引用密度/活跃度 4 指标）
- **AND** 展示快捷操作（开始提问/导入文档/浏览配方）
- **AND** 当知识库为空时，展示种子导入引导卡片

#### Scenario: 已有内容的首页
- **WHEN** 用户已有文档与问答历史
- **THEN** 展示最近 3 条问答历史
- **AND** 展示推荐配方（每日推荐或最近浏览）
- **AND** 展示飞轮健康度趋势（本周 vs 上周）

### Requirement: 问答历史搜索
系统 SHALL 提供问答历史搜索功能，支持全文检索与时间筛选。

#### Scenario: 搜索历史问答
- **WHEN** 用户在问答页点击"历史"入口
- **THEN** 展示历史问答列表（默认最近 50 条）
- **WHEN** 用户输入关键词
- **THEN** 对问题+答案+引用内容做全文搜索
- **AND** 高亮匹配关键词
- **AND** 支持按时间范围筛选

### Requirement: 设置中心
系统 SHALL 提供统一设置中心（/settings），聚合标签管理、数据导出、审计日志。

#### Scenario: 访问设置中心
- **WHEN** 用户点击导航的"设置"
- **THEN** 展示设置中心，含三个子模块入口：标签管理/数据导出/审计日志
- **WHEN** 用户选择子模块
- **THEN** 展示对应功能面板，不离开设置页

### Requirement: 上下文感知导入
系统 SHALL 根据当前所在 tab，提供上下文感知的导入操作。

#### Scenario: 在文档 tab 导入
- **WHEN** 用户在文档库 tab
- **THEN** 顶部操作按钮显示"导入文档"
- **AND** 点击触发文档导入对话框

#### Scenario: 在配方 tab 创作
- **WHEN** 用户在配方 tab
- **THEN** 顶部操作按钮显示"创作配方"
- **AND** 点击跳转到配方编辑器

## MODIFIED Requirements

### Requirement: 导航结构
原 5 平铺 tab 重组为分组导航。

**修改前**：问答 / 实验室 / 配方 / 文档 / 管理（5 平铺）
**修改后**：
- 首页（/）
- 知识：问答（/chat）| 文档（/docs）
- 调酒：配方（/recipes）| 实验室（/lab）
- 设置（/settings）

### Requirement: 冷启动引导链
补全 L1-L2 引导环节。

**修改前**：年龄门 → 直接进问答页
**修改后**：年龄门 → 首页价值认知 →（空库时）种子导入引导 → 首次问答 → 溯源引导

## REMOVED Requirements

### Requirement: 顶部全局"导入"按钮
**Reason**：与文档 tab 的导入功能重复，改为上下文感知导入
**Migration**：移除顶部全局导入按钮，各 tab 内提供上下文导入操作
